Powerful Features

🎨 Visual Designer

Drag-and-drop interface for designing Minecraft GUIs with panels, buttons, labels, slots, inputs, and more.

⚡ Real-time Preview

See your GUI come to life instantly with interactive preview that supports events, conditions, and navigation.

📝 Java Code Generation

Generate clean, production-ready Java code for Forge 1.20.1, NeoForge 1.20.1, and NeoForge 1.21.1.

🔧 Custom Variables & Functions

Define custom variables and functions with full type support (int, boolean, String) and direct Java code editing.

🧩 Container Menus

Support for inventory screens with real slots, menus, and registries. Build chest, furnace, and custom containers.

🌍 Multi-language Support

Full i18n support with 11 languages including English, Italian, French, German, Spanish, and more.

🤖 AI Assistance

Optional Ollama integration for AI-powered GUI generation with streaming responses and coordinate correction.

📦 Mod Import

Scan existing mods and import Java screens directly into the visual editor for modification.

🔗 Navigation System

Easy screen-to-screen navigation with parent/child relationships and overlay support for title and pause menus.
